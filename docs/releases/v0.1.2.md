清录首个 GitHub 开发预览版，面向鸿蒙电脑 `2in1`，要求 API 24 / `6.1.1(24)` 及以上。

- 整个桌面录制，支持原分辨率、长边最高 2560 / 1920。
- 自动码率、2 / 4 / 8 / 12 / 20 / 30 Mbps 预设及 1–30 Mbps 自定义值，便于控制视频体积。
- 系统声音、可选麦克风、停止保存、列表预览和导出。

## 下载与安装

`Qinglu-0.1.2-2in1-api24-unsigned.hap` 为 **release 模式、未签名** HAP，不能下载后直接双击安装。请先校验 `SHA256SUMS`，再按 [安装指南](https://github.com/PengJunchen/harmony-desktop-recorder/blob/v0.1.2/docs/INSTALL.md) 使用自己的华为开发者签名和包含本人设备的有效 Profile 完成签名安装。推荐下载同版本源码 ZIP，通过 DevEco 自动签名运行。

附件另含 `INSTALL.md`（离线指南）、`release-manifest.json`（源码提交与包信息）和源码 ZIP。不提供个人设备签名包、证书、Profile 或测试报告。

## 已知边界

这是开发预览版，尚未上架应用市场。仅支持电脑 `2in1`；受保护画面 / 音频受系统限制；帧率由系统管理，不保证固定 60 fps；暂不提供暂停、剪辑和多屏拼接。卸载会删除应用私有目录中的录像，请先导出重要文件。Profile 到期后需要重新签名安装。
