## 短介绍

面向鸿蒙电脑的本地桌面录屏工具，独立调整分辨率与视频码率，预估体积，管理并导出录制视频。

## 详细介绍

清录为教学、操作演示和工作说明提供本地桌面录制。通过系统授权选择屏幕后，将画面与系统允许采集的播放声音保存为 MP4。麦克风默认关闭，可按需开启讲解。

- 原分辨率、长边最高 2560 / 1920，保留屏幕比例。
- 视频码率独立于分辨率，可选预设或自定义 1–30 Mbps，最多两位小数，并显示每分钟体积参考。
- 录像列表支持预览、导出、单条删除；可清空本机录像和诊断信息。
- 隐私政策在应用内可随时查看；可撤回同意并停止录屏。
- 无需注册，录像不上传至开发者服务器。

仅适用于受支持的鸿蒙电脑；隐私窗口、版权保护画面及音频受系统限制。帧率由系统管理，不承诺固定 60 fps。导出视频及分享内容由用户自行决定。

## 审核说明草稿

1. 应用仅声明麦克风权限，在用户主动选择麦克风讲解并开始录制时申请；拒绝后可关闭讲解继续录屏。
2. 开始录屏必须经系统授权选择屏幕，应用未调用豁免隐私窗口或绕过授权的接口。
3. 画面、音频、诊断及同意记录仅在本机处理；未集成联网、广告、统计 SDK。隐私申报以实际包和平台字段定义为准，不填写虚假的“完全不处理信息”。
4. 使用步骤：阅读政策并同意 → 选择分辨率 / 码率 → 开始录制并完成系统授权 → 停止保存 → 播放 / 导出 / 删除。
5. 撤回同意及清除入口位于“隐私与关于”；不设账号体系，因此不涉及账号注销。
6. 功能定位侧重演示录制时的分辨率与码率独立控制、体积预估及本地文件管理。是否满足平台实质价值要求，以实际审核为准，不声称获得预先批准。
